# Lightning Browser fork

This repository is a fork of [Anthony Restaino’s Lightning Browser](https://github.com/anthonycr/Lightning-Browser). The upstream project and its contributors retain credit for the original code and design.

The default branch in this fork is `browser2`. Review the branch history to see changes specific to this fork. This repository should not be read as authorship of the upstream browser.

For the original project overview, features, downloads, contribution guidance, and license, see the [upstream README](https://github.com/anthonycr/Lightning-Browser#readme).

## Building

Open the project in Android Studio and sync Gradle. The repository includes the Gradle wrapper. Verify the current branch builds with your Android Studio and SDK versions before distributing an APK.
